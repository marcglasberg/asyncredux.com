# Provider

If your app already uses [Provider](https://pub.dev/packages/provider),
[provider_for_redux](https://pub.dev/packages/provider_for_redux) shows how to integrate it
with AsyncRedux. Its `ReduxSelector` subscribes widgets to selected state.

For the standard AsyncRedux setup, see [Using the store state](../basics/using-the-store-state).
